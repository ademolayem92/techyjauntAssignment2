# techyjauntAssignment2

This assignment-solution.md is a full write-up of a Node.js + MongoDB/Express API debugging and hardening exercise. It explains how the app behaves under different student lookup, update, validation, and error-handling scenarios, then provides a corrected implementation of the server in app.js with improved validation, route checks, and case-insensitive search. It also includes test cases showing expected HTTP responses for successful and failing requests.
